# Filling forms

1. Read the whole form first (browser_read in a browser, read_screen elsewhere), scrolling to the end: list every
   field, which are required, and any rules (formats, character limits).
2. Fill each field from what the user said or memory (recall) holds. Never invent a value: for anything you don't
   know, leave it empty and ask, all the missing ones in one question.
3. Type into the right field (browser_type with its label), one at a time, then read the form again to check each
   value landed where it should and no error appeared.
4. Before submitting, show the user what you entered (field: value, one per line) and ask. Submitting, paying or
   sending is always their call.

## Never
Type passwords, one-time codes, card or bank numbers, or government ID numbers: ask the user to enter those
themselves. Never tick boxes that agree to terms or marketing on the user's behalf without asking. Never solve
captchas.
