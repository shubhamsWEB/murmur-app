## What's new

**Summarise any document you have open.** Ask about a PDF in Preview or Acrobat, or a Word, RTF or text file, and Murmur reads it from the file itself: "summarise pages 1 to 22" gives you those pages, even in a 470-page book, with nothing extra to install. Page numbers can be said in words ("page one to page twenty two").

## Fixes

- Home no longer says Murmur can't type into other apps after you've allowed it in Accessibility. It updates within a couple of seconds, without restarting Murmur.
- "The PDF is open, read it" is now treated as a request about the document on screen, not a search for files.
- If macOS hasn't let Murmur read the folder a document is in, Murmur says so and tells you where to allow it, instead of giving up without saying why.
