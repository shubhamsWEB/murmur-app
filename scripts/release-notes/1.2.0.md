## What's new

**Hinglish is faster.** Murmur used to decode a Hinglish dictation again, up to five more times, whenever the model wasn't sure of itself, and then keep the last and most random attempt. Writing Hindi in English letters often looks "unsure" by that measure, so a sentence could take six passes. Now it decodes once, and again only if the model gets stuck repeating itself. The first Hinglish dictation after launch is quick too: the model warms up in the background.

**Fits the sentence.** Dictate into the middle of a sentence and Murmur adds the space before it and leaves out the capital and the full stop; start a new one and it gets its capital. Only spacing, the first letter and the last full stop change, never your words. Turn it off in Settings → Speech → Fit to the sentence.

**Other languages are more accurate.** They now use Parakeet Ultra, which makes fewer mistakes in all 25 languages (average error rate on the FLEURS test set down from 14.8 % to 11.7 %) at the same speed. Already using Other languages? Settings → Speech → Update (about 630 MB). Dictation keeps working while it downloads, and the old model's space is freed afterwards.
