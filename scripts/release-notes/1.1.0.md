## What's new

**Your keys, your way.** Hold **fn** and Murmur works out whether you're writing or asking. Now add **⇧** to only type (never a command), or **⌃** to only run a command. Every shortcut can be changed in Settings → Shortcuts: the talk key (fn, Right ⌥ or the new Right ⌘), the two keys held with it, and file search (⇧⌘Space). Setup and the website show all four.

**More skills, longer jobs.** Murmur comes with new skills for going through email, catching up on chats, researching on the web, comparing prices when shopping, filling in forms, and working through long tasks item by item. Add your own from a GitHub link in Settings → Skills. If a big job runs out of time, say **"continue"** and it picks up where it stopped.

**Summaries of the whole page.** "Summarise this" and "what am I seeing" read all of a web page, not just the part on screen, even when Chrome doesn't let Murmur script its pages.

**Questions about your messages.** "What did I send Arjun on WhatsApp today?" or "check my emails" is answered, not typed into the box you're in.

## Fixes

- Opening your documents: "open my PAN card" or "aadhaar card kholo" finds the file by its name (PanCard.pdf, Aadhar.pdf), the model's reading of what you asked is no longer replaced, and "my driving license and PAN card" opens both. Tests now hold this, so it can't quietly break again.
- Big jobs no longer stop half-way to ask you to "say continue", tick off steps they didn't do, or summarise a chat without opening it.
- First launch downloads nothing until you choose. Setup says what it downloads (the file search model, then the speech model for your language), one at a time, so each is fast, and the file search model is named wherever its progress shows.
