Settings

How dictation listens and types, and how Murmur runs.

Dictation
Dictation Hold the dictation key and talk; let go and the words are typed where you're typing. Speech is turned into text on this PC: nothing you say leaves it.
Dictation key Pressing another key while it's held (a shortcut such as Ctrl + Windows + D) cancels the dictation.
Language
MicrophoneThe default follows Windows' sound settings.
Quiet Voice Lifts a soft or whispered voice (up to 40 dB) before it's turned into words, so you can dictate quietly in a shared room.
Murmur button on screen A small Murmur pill you can drag anywhere. Click it to open Murmur; the listening pill grows out of it while you talk.
Recordings and history
Keep a history Used for “This week” on Home. Stays on this PC.
Keep recordings Saves every recording and what Murmur heard to Documents › Murmur Recordings, to compare speech models.

Murmur
Open Murmur when you sign in Murmur lives in the tray, listens for the dictation key and keeps your folders indexed.
Clicking the tray icon Right-click it for the menu.
Center the search panel Centered, Murmur keeps a transparent window over the whole screen: about 50 MB more memory on a 1080p screen.
Run the search model on the processor Murmur uses the graphics card where it measured faster. If searches find nothing or the wrong files, turn this on: the model then runs on the processor, more slowly, from the next indexing on.

Code

Murmur can find code by what it does. Type “code:” in the search and say what the code does. Results open in your editor at the line.

Open code in Murmur reads what git keeps: source, configuration, docs and notebooks. It leaves out what git ignores, dependencies, build output, data files, keys and password files.

Privacy

Murmur turns speech into text and reads the folders you choose on this PC. It goes online only to download its models, once, and to check for updates, which sends nothing about you or your files.
